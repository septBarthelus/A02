# A02 – Git, GitHub, and WebStorm Tutorial

## Introduction

The purpose of this tutorial is to explain how to use Git, GitHub, and WebStorm together. It is written for someone who has little or no experience using these tools.

By the end of this tutorial, you should understand how to create a GitHub repository, clone it into WebStorm, edit files, commit changes, and push those changes back to GitHub.

---

# Part 1: Required Software and Accounts

Before starting, you will need:

- A GitHub account
- Git installed on your computer
- WebStorm installed on your computer
- An internet connection

---

# Step 1: Create a GitHub Account

1. Open a web browser.
2. Go to https://github.com/
3. Click **Sign up**.
4. Enter your email address.
5. Create a password.
6. Choose a username.
7. Complete the verification process.
8. Sign in to your new GitHub account.

GitHub is where the remote copy of the project will be stored.

---

# Step 2: Download and Install Git

Git is the version control system that keeps track of changes made to the project.

1. Go to https://git-scm.com/downloads
2. Select the download for your operating system.
3. Open the downloaded installer.
4. Follow the installation instructions.
5. Complete the installation.

To check whether Git is installed, open a terminal and enter:

git --version
